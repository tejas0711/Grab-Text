# Grab Text ✨

**Grab text from anywhere on your screen — instantly.**

Grab Text is a lightweight Chrome extension that uses OCR (Optical Character Recognition) to extract text from selected screen regions and copy it to your clipboard. Works on YouTube videos, webpages, social media, and more.

## ✨ Features

- **Quick Selection** — Press `Ctrl + Shift + E` or click the extension icon.
- **Screen OCR** — Select any region to extract visible text, including text in video frames.
- **Local Processing** — Uses Tesseract.js to recognize text directly on your device.
- **Instant Copy** — Extracted text is automatically copied to your clipboard.
- **Multi-language Support** — English by default, with additional languages available.
- **Privacy-Focused** — No screenshots are sent to an external OCR service.

## 🚀 Installation

1. Download or clone this repository.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the project folder.
5. Open any webpage and press `Ctrl + Shift + E` to get started.

## 🛠️ Built With

- JavaScript
- Chrome Extensions API (Manifest V3)
- Tesseract.js
- HTML & CSS

## 🔒 Privacy

OCR processing runs locally using bundled Tesseract.js components. Additional language data may be downloaded when you select another language.
